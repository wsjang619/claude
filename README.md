# 별내동 인근 청약 알림

경기도 남양주시 별내동 부근에 청약 공고가 올라오면 이메일로 알려줍니다.
서버 없이 GitHub Actions가 하루 두 번(08:07, 18:07 KST) 돌며, 파이썬 표준 라이브러리만 씁니다.

## 무엇을 알려주나

- **신규 공고**: 청약홈(APT 분양·무순위·오피스텔/도시형·공공지원민간임대·임의공급)과 LH 분양임대 공고 중 별내동·남양주·인근(구리·의정부)·경기북부 광역공고에 해당하는 것
- **접수 임박**: 이미 알린 공고의 접수 시작 하루 전(당일 포함) 한 번 더
- 메일에는 접수 기간(D-day), 당첨자 발표일, 세대수, 특별공급 유형별 세대수, 공고 링크가 들어가고, 가구 정보([profile])에 맞춘 **내 조건 체크**가 함께 붙습니다.
- 이미 알린 공고는 `state/seen.json`에 기록해 중복 발송하지 않습니다.

> '내 조건 체크'는 어떤 공급유형을 공고문에서 확인해 볼지 알려주는 참고용입니다. 소득·자산·무주택 요건 등 최종 자격은 각 공고문이 기준입니다. 무주택세대구성원이라고 가정했으니 아니라면 `config.toml`의 `homeless`를 바꾸세요.

## 설정 순서

1. **공공데이터포털 인증키** — [data.go.kr](https://www.data.go.kr)에서 아래 두 API를 각각 활용신청하고 일반 인증키를 받습니다(승인·반영에 최대 1~2시간).
   - 한국부동산원 청약홈 분양정보 조회 서비스
   - 한국토지주택공사 분양임대공고문 조회 서비스
2. **Gmail 앱 비밀번호** — 2단계 인증을 켠 뒤 Google 계정 > 보안 > 앱 비밀번호에서 발급합니다. 다른 메일 서비스는 `SMTP_HOST`/`SMTP_PORT`로 지정합니다.
3. **GitHub Secrets** — 저장소 Settings > Secrets and variables > Actions에 등록합니다.

   | 이름 | 값 |
   |---|---|
   | `DATA_GO_KR_SERVICE_KEY` | 공공데이터포털 인증키 (Encoding/Decoding 어느 쪽이든 가능) |
   | `SMTP_USER` | 보내는 Gmail 주소 |
   | `SMTP_PASSWORD` | 앱 비밀번호 |
   | `MAIL_TO` | 받을 주소 (비우면 `SMTP_USER`로 발송) |

4. 기본 브랜치에 병합한 뒤 Actions 탭 > "청약 알림" > Run workflow에서 `dry_run`을 켜고 실행해 조회가 되는지 봅니다. 스케줄 실행은 기본 브랜치에서만 동작합니다.

## 로컬 실행

```bash
export DATA_GO_KR_SERVICE_KEY=...
python -m cheongyak_alert --dry-run      # 조회·매칭 결과만 출력 (발송·저장 없음)

export SMTP_USER=you@gmail.com SMTP_PASSWORD=앱비밀번호
python -m cheongyak_alert --test-mail    # 샘플 메일로 SMTP 설정 확인
python -m cheongyak_alert                # 실제 실행
python -m unittest discover -s tests -t .
```

`config.toml`에서 지역 키워드·조회 기간·재알림 시점·가구 정보를 바꿀 수 있습니다.
조회가 일부 실패하면 나머지는 정상 처리하고 종료 코드 1로 끝나 Actions가 실패 메일을 보냅니다. 메일 발송이 실패하면 상태를 저장하지 않아 다음 실행에서 다시 시도합니다.

## 알아둘 점

- 개발 환경에서 공공데이터포털에 접속할 수 없어 **실제 API 응답으로는 아직 검증하지 못했습니다.** 테스트는 목 응답 기준입니다. 첫 `dry_run` 결과에서 `! ...` 오류 줄이 보이면 알려주세요. 특히 LH 엔드포인트·파라미터명(`lhNoticeInfo1`)은 `config.toml`의 `[lh] endpoint`로 바꿀 수 있습니다.
- LH 공고는 주소 필드가 없어 공고명에 지역 키워드가 있는 것만 잡힙니다.
- SH(서울)·GH(경기주택도시공사) 자체 공고, 민간 사전청약·견본주택 오픈 소식은 포함하지 않습니다. 민간 분양은 청약홈 공고로 잡힙니다.
- 저장소에 커밋이 60일간 없으면 GitHub이 스케줄 워크플로를 멈출 수 있습니다. 새 공고가 생겨 `state/seen.json`이 갱신되면 이어지지만, 멈추면 Actions 탭에서 다시 켜 주세요.
- `config.toml`의 `[profile]`에는 출생연도·혼인 연월·자녀 출생 연월이 들어 있습니다. 저장소를 공개로 바꿀 계획이면 먼저 지우세요.
