# 별내동 인근 청약·전세 매물 알림

경기도 남양주시 별내동 부근에 청약 공고가 올라오면 이메일로 알려줍니다.
서버 없이 GitHub Actions가 하루 두 번(08:07, 18:07 KST) 돌며, 파이썬 표준 라이브러리만 씁니다.

## 무엇을 알려주나

- **신규 공고**: 청약홈(APT 분양·무순위·오피스텔/도시형·공공지원민간임대·임의공급)과 LH 분양임대 공고 중 별내동·남양주·인근(구리·의정부)·경기북부 광역공고에 해당하는 것
- **접수 임박**: 이미 알린 공고의 접수 시작 하루 전(당일 포함) 한 번 더
- 알림은 기본적으로 **jos5324@gmail.com**으로 갑니다(`config.toml`의 `[mail] to`).
- 공고마다 **요약 문단**(규모, 접수 기간과 D-day, 당첨자 발표일, 특별공급 세대수)과 상세 표(전용면적, 분양가 범위, 사업주체, 문의처)가 들어가고, 여러 건이면 맨 위에 한눈에 보기가 붙습니다.
- **관련 링크**: 공고 상세, 단지 홈페이지(있는 경우), 청약홈 또는 LH청약플러스, 네이버 지도 검색.
- 가구 정보(`[profile]`)에 맞춘 **내 조건 체크**도 함께 붙습니다.
- 이미 알린 공고는 `state/seen.json`에 기록해 중복 발송하지 않습니다.

> '내 조건 체크'는 어떤 공급유형을 공고문에서 확인해 볼지 알려주는 참고용입니다. 소득·자산·무주택 요건 등 최종 자격은 각 공고문이 기준입니다. 무주택세대구성원이라고 가정했으니 아니라면 `config.toml`의 `homeless`를 바꾸세요.

## 설정 순서

1. **공공데이터포털 인증키** — [data.go.kr](https://www.data.go.kr)에서 아래 두 API를 각각 활용신청하고 일반 인증키를 받습니다(승인·반영에 최대 1~2시간).
   - 한국부동산원 청약홈 분양정보 조회 서비스
   - 한국토지주택공사 분양임대공고문 조회 서비스
2. **Gmail 앱 비밀번호** — 2단계 인증을 켠 뒤 Google 계정 > 보안 > 앱 비밀번호에서 발급합니다. 다른 메일 서비스는 `SMTP_HOST`/`SMTP_PORT`로 지정합니다.
3. **GitHub Secrets** — 저장소 Settings > Secrets and variables > Actions에 등록합니다. 받는 주소를 `config.toml`과 다르게 쓰고 싶을 때만 `MAIL_TO` 시크릿을 추가하세요(있으면 그쪽이 우선).

   | 이름 | 값 |
   |---|---|
   | `DATA_GO_KR_SERVICE_KEY` | 공공데이터포털 인증키 (Encoding/Decoding 어느 쪽이든 가능) |
   | `SMTP_USER` | 보내는 Gmail 주소 |
   | `SMTP_PASSWORD` | 앱 비밀번호 |

4. 기본 브랜치에 병합한 뒤 Actions 탭 > "청약 알림" > Run workflow에서 `dry_run`을 켜고 실행해 조회가 되는지 봅니다. 스케줄 실행은 기본 브랜치에서만 동작합니다.

## 로컬 실행

```bash
export DATA_GO_KR_SERVICE_KEY=...
python -m cheongyak_alert --dry-run      # 조회·매칭 결과만 출력 (발송·저장 없음)

export SMTP_USER=you@gmail.com SMTP_PASSWORD=앱비밀번호
python -m cheongyak_alert --test-mail    # 샘플 메일로 SMTP 설정 확인
python -m cheongyak_alert                # 실제 실행
python -m unittest discover -s tests -t .
```

`config.toml`에서 지역 키워드·조회 기간·재알림 시점·가구 정보를 바꿀 수 있습니다.
조회가 일부 실패하면 나머지는 정상 처리하고 종료 코드 1로 끝나 Actions가 실패 메일을 보냅니다. 메일 발송이 실패하면 상태를 저장하지 않아 다음 실행에서 다시 시도합니다.

## 알아둘 점

- 개발 환경에서 공공데이터포털에 접속할 수 없어 **실제 API 응답으로는 아직 검증하지 못했습니다.** 테스트는 목 응답 기준입니다. 첫 `dry_run` 결과에서 `! ...` 오류 줄이 보이면 알려주세요. 특히 LH 엔드포인트·파라미터명(`lhNoticeInfo1`)은 `config.toml`의 `[lh] endpoint`로 바꿀 수 있습니다.
- 공고문 PDF 원문은 첨부하지 않고 공고 상세 링크로 안내합니다(요약은 API가 주는 항목 기준).
- LH 공고는 주소 필드가 없어 공고명에 지역 키워드가 있는 것만 잡힙니다.
- SH(서울)·GH(경기주택도시공사) 자체 공고, 민간 사전청약·견본주택 오픈 소식은 포함하지 않습니다. 민간 분양은 청약홈 공고로 잡힙니다.
- 저장소에 커밋이 60일간 없으면 GitHub이 스케줄 워크플로를 멈출 수 있습니다. 새 공고가 생겨 `state/seen.json`이 갱신되면 이어지지만, 멈추면 Actions 탭에서 다시 켜 주세요.
- `config.toml`의 `[profile]`에는 출생연도·혼인 연월·자녀 출생 연월이 들어 있습니다. 저장소를 공개로 바꿀 계획이면 먼저 지우세요.

# 전세 매물 알림

네이버부동산에 조건에 맞는 전세 매물이 새로 올라오면 같은 주소로 메일을 보냅니다.
`python -m cheongyak_alert --listings` 로 실행하며, 워크플로(`listing-alert.yml`)가 3시간마다(07~22시 KST) 돌립니다.

| 조건 | 기본값 (`config.toml`의 `[listings]`) |
|---|---|
| 지역 | 별내동(1순위), 다산동·퇴계원읍, 구리 갈매동 |
| 유형 | 아파트, 빌라(연립·다세대주택) — 네이버의 `빌라` 분류는 다세대빌라·다세대주택을 포함 |
| 전용면적 | 59~85㎡ |
| 거래 | 전세, 보증금 3억 이하 |

- **첫 실행**은 현재 올라와 있는 매물을 기준선으로 한 번 보내고(최대 30건), 이후에는 새로 올라온 것만 보냅니다. 알린 매물은 `state/listings.json`에 기록합니다.
- 메일에는 보증금·전용면적·층·중개사·확인일, 네이버부동산 매물 링크, 지도 링크가 들어갑니다.
- **시세 참고**: 국토부 전세 실거래가로 동별 최근 3개월 최저·중간·최고가와 같은 단지의 최근 거래를 붙입니다. 이를 위해 공공데이터포털에서 **아파트 전월세 실거래가**와 **연립다세대 전월세 실거래가** 자료도 활용신청해야 합니다(청약 알림과 같은 인증키).
- 동 이름이나 순위는 `[[listings.areas]]`에서 바꿉니다. `path`는 경기도 아래 (시군구, 읍면동) 이름이고, `lawd_cd`는 시군구 코드입니다(남양주 41360, 구리 41310).

## 네이버부동산 조회의 한계 — 꼭 읽어 주세요

- 네이버는 매물 공식 API를 제공하지 않습니다. 이 기능은 웹 화면이 쓰는 비공식 주소를 호출하며, **네이버 이용약관상 허용되지 않을 수 있습니다.** 개인용으로 낮은 빈도(요청 사이 2초 대기, 하루 6회)만 쓰도록 했고, 차단되면 우회하지 않고 오류로 알립니다.
- 네이버가 화면·주소를 바꾸면 언제든 동작하지 않을 수 있습니다.
- GitHub Actions 서버 IP는 차단될 가능성이 높습니다. `HTTP 401/403/429` 오류가 나면 둘 중 하나를 쓰세요.
  1. 브라우저로 new.land.naver.com에 접속해 개발자도구(네트워크 탭)에서 요청 헤더의 `Authorization: Bearer ...` 토큰을 복사해 `NAVER_LAND_TOKEN` 시크릿으로 등록(토큰은 몇 시간 뒤 만료됩니다).
  2. 집 PC나 라즈베리파이처럼 가정용 IP에서 `python -m cheongyak_alert --listings`를 cron/작업 스케줄러로 실행(환경변수 `SMTP_USER`, `SMTP_PASSWORD`, `DATA_GO_KR_SERVICE_KEY` 필요). Actions의 self-hosted runner로 같은 워크플로를 돌려도 됩니다.
- 직방·다방은 지원하지 않습니다.
- 개발 환경에서 네이버·공공데이터포털에 접속할 수 없어 **실제 응답으로는 검증하지 못했습니다.** 테스트는 목 응답 기준입니다. 첫 `dry_run`의 `! ...` 오류 줄을 알려주시면 맞춰 고치겠습니다.

# 알림이 오지 않을 때 (확인용 링크 모음)

- **메일 설정(`SMTP_USER`, `SMTP_PASSWORD` 시크릿)이 없으면** 알림 메일을 보낼 수 없습니다. 이때 Actions에서는 **GitHub 이슈**를 만들어 `@소유자`를 멘션하고, GitHub이 그 내용을 이메일로 보냅니다(시크릿 불필요, `[mail] fallback_issue = false`로 끌 수 있음). 시크릿을 등록하면 jos5324@gmail.com으로 직접 메일이 갑니다.
- **조회 자체가 안 되면**(인증키 없음, 네이버부동산 차단·접속 실패 등) 실패로 끝내지 않고 **확인용 링크 모음**을 보냅니다. 청약홈·LH청약플러스·마이홈포털·남양주시청, 지역별 네이버부동산 지도(전세·아파트/빌라), 직방·다방, 국토부 실거래가 링크가 들어가며 하루 한 번만 보냅니다.
- 링크 모음을 지금 받으려면 `python -m cheongyak_alert --links` (또는 Actions 수동 실행).
- 네이버부동산 링크는 지도 중심·매물유형·전세까지만 지정합니다. 가격·면적 필터는 열린 화면에서 설정해야 하고, 링크 형식은 네이버가 바꾸면 달라질 수 있습니다. 지도 중심 좌표는 `config.toml`의 `lat`/`lon`(대략값)입니다.
- 정상 알림 메일에도 지역별 네이버부동산 목록 링크가 함께 들어갑니다.
